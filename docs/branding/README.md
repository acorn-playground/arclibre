# ArcLibre's icon

`arclibre-icon.svg` is the source: the RISC OS acorn on the grey of
ArcLibre's boot splash, over a purple strip holding its ROM, drawn on the
macOS 1024 icon grid to sit beside MacBeeb's and MacArch's icons. The PNGs
are renderings of it at 1024, 512 and 128 pixels, with transparent corners.

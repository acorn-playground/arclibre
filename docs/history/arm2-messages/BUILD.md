# Build and reproduce

Keep this directory beside the previous experiment directories. The source snapshots and resource bytes are included; rebuilding does not require network access or a proprietary ROM. The previous keyboard milestone supplies the pinned restored kernel and headers. Its original source/patch artifacts remain immutable inputs.

From the project root:

```sh
export MACARCH_CORE=/absolute/path/to/macarc/Packages/ArchimedesCore
sh experiments/arm2-messages/scripts/run.sh
```

Requirements are the previously working AsAsm and observer tools, Python 3, macOS/Swift, and unchanged MacArch core commit `550bee4842e45eafdf331f0d06e11df1368403e8`. The recorded host uses Swift 6.4 with the same native SwiftPM backend as the earlier experiments. `ASASM` and `ASASM_OBSERVER` override the default tools in `arm2-kernel/toolchain/gccsdk/tools/asasm/src/asasm` and `arm2-restoration/toolchain/asasm/src/asasm`. Tool reconstruction is documented in the restoration's `BUILD.md`.

The recipe regenerates headers from the preceding restored source tree and checks the original export hashes, applies patches 16–18, builds each module twice normally and once with the observer, audits all emitted instructions, and packages the ROM. It then performs three fresh reset-to-pre-module runs, three natural continuations, three CAM fixture suites, three keyboard/Help suites, three MessageTrans client suites, font/pixel tests and independent verification. Every recipe operation was executed successfully; captures and validation were run in stages during development. `logs/final-validation.log` records the final acceptance checks.

Expected hashes:

```text
unchanged kernel.bin cd2c3eb18de6ffab8fabb59406efb50eafd6851c305a58e88e2cc554facfcc30
messages.rom         0f0313ba250d83879206fc979dd40de5846b4516f98beed86e3c4156412ac653
```

To rebuild only the modules/container:

```sh
python3 experiments/arm2-messages/scripts/build_modules.py
python3 experiments/arm2-messages/scripts/audit_modules.py
python3 experiments/arm2-messages/scripts/package_rom.py
```

To inspect the supplied execution evidence without claiming a fresh boot:

```sh
python3 experiments/arm2-messages/scripts/verify_regressions.py
python3 experiments/arm2-messages/scripts/verify_keyboard.py
python3 experiments/arm2-messages/scripts/verify_messages.py
python3 experiments/arm2-messages/scripts/finalize.py
```

`patches/series` is incremental after the keyboard milestone. For manual replay, copy this experiment's `sources/` to a work directory and copy the preceding `work/HdrSrc/hdr/CPU/Generic26` to `SharedHeaders/CPU/Generic26` there. Apply each patch with `patch -p1 -F 0`. The finalizer checks exact replay against the compiled inputs. `Messages/ResourcesData` is generated by the resource packer rather than patched source.

Load `artifacts/messages.rom` in MacArch as A440/1, ARM2, 4 MiB, standard monitor, no media, with default CMOS/Delete held at cold power-on. At Supervisor, type `Help`. The image includes only a read-only ROM filesystem, not disc drivers or a desktop.

`python3 experiments/arm2-messages/scripts/package_evidence.py` creates a verified source/ROM/evidence archive and SHA-256 sidecar. The preceding evidence archive is included with earlier dependencies nested; extract into a common parent when reconstructing the sibling experiment directories. Native harness build products, compiler caches and host tool binaries are excluded.

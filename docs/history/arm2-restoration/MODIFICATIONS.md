# Reviewable source changes

Original snapshots are immutable in `sources/`. restore.py reconstructs `work/` and emits the following ordered unified diffs. provenance.py independently applies the saved series with `patch -p1 -F 0` and compares the result byte-for-byte to `work/` (excluding regenerated help). The patch manifest is machine-readable.

| Patch | Reason and behavioural effect |
|---|---|
| 0001 | Explicitly select no Morris/IOMD, Dallas ID or IOEB on A440/1. Select the existing non-POST reset path and original 8-bit sound. The omitted TestSrc monitor/POST is not replaced with a success stub. |
| 0002 | Only NewCDA's expanded mapping path accepts `PageFlags_Unavailable`. The real original MEMC1 path passes `AP_SysHeap` and retains its packed CAM implementation. No workspace layout is changed. |
| 0003 | Reconcile OS_ReadSysInfo reasons 2/4/5 with a board lacking Dallas identity hardware. Initialise the existing eight-byte `UniqueMachineID`; return the documented unavailable identity/address result. Select the real original-board machine type without probing absent IOEB/LC hardware. Preserve the conditional real-chip implementations for their original profiles. |
| 0004 | Rename the historic `ENTRY` macro to `KernelEntry`, avoiding AsAsm's built-in directive. Move the IOC table counter declaration to file scope. This is a source/dialect correction, not a replacement interrupt implementation. |
| 0005 | Remove three zero-valued legacy `Module_SWI*Base` aliases from the later allocation header. Full public allocation addresses remain; original ModHand class constants retain their genuine values. |
| 0006 | Correct the public `BadFileName` alias's case. Make the existing ModeNotAvailable error block available to its numeric-mode caller as well as selector paths. Gate the IOMD monitor-latch routine with the same MorrisSupport condition used by its callers. |
| 0007 | Add explicit word alignment before affected entry labels and data tables, and after an inline message whose return rounds upward. Avoid symbols pointing before AsAsm's automatically aligned instruction. |
| 0008 | Encode the actual IRQ branch copied to RAM `&18` using the ARM2 modulo-26-bit PC and signed 24-bit word displacement. The decoded target is independently verified; no guessed instruction constant suppresses a range error. |
| 0009 | Add register/flag-preserving `MOV r0,r0` at 174 selected source sites after PSR changes or user-bank loads. Macro expansion yields 198 checked emitted settling sites. The fixed SWI dispatcher has one explicit same-SVC-mode exception, preserving its 116-byte contract. The exact source-site inventory is recorded. |
| 0010 | Do not emit ARM3 CP15 detection/cache-control instructions for this explicitly fixed ARM2 target. These were found by the independent instruction gate even after successful assembly. |
| 0011 | Expand one error-block address from ADR to ADRL after additional instructions move it beyond a single immediate's reach. |

`s/TMOSHelp` is regenerated by the real tokeniser from this cohort's `HelpStrs` and `Tokens`; its provenance comment does not emit target bytes. Generated hashes are in the provenance report. No manually invented help/resource payload is substituted.

The separate AsAsm observation patch logs instruction/data emission, symbol values and selected references. It changes neither instruction encoding nor expression/symbol semantics. It is applied only to an isolated tool copy; the normal and observed AOF files must match exactly. This GPL-covered tool patch is not a kernel source patch. The reused host tokeniser type fixes and Darwin compatibility headers are preserved in host bootstrap evidence.

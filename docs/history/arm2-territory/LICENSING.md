# Licensing and provenance

No proprietary ROM image, ROM code, font or other resource was used. The original source snapshots, individual hashes and repository revisions are retained under `sources/` and `manifests/`; patches apply only to isolated copies.

- TerritoryManager's original pinned repository includes Apache-2.0 `LICENSE`, source notices and the SystemDisc sprite source. The sprite is rebuilt from that public asset; its original tokenized BASIC MakeSprite describes the compression contract but is not executed or incorporated into the ROM.
- The original UK snapshot has explicit Acorn Apache-2.0 notices in its source files and Makefile, but **no standalone LICENSE file** at that revision. Its plain message resource has no separate file-level notice. Those facts are preserved rather than adding a purported original license file. `licenses/uk-resource-provenance/` records a later publicly Apache-licensed TerritoryModule resource/license comparison: original token values recur there apart from the obsolete TR13 placeholder and `HongKong` becoming `Hong Kong`. That comparison is corroborating provenance only; all runtime bytes remain from the original UK pin. The experiment's root LICENSE supplies the Apache text and does not replace third-party notices.
- The inherited FileSwitch, ResourceFS, MessageTrans, Messages, kernel resources and public interfaces retain the earlier milestone's pinned public Apache-2.0 licensing and original notices.
- Squash's portable `cssr`, `zssr`, associated definitions and interface headers carry **Jon Thackray's BSD three-clause license**, reproduced in `licenses/Squash-BSD3` and retained in each original file. Its debug header and other Acorn wrappers carry their own Apache-2.0 notices. Do not describe all Squash files as Apache-only. These algorithms are a host asset-building dependency; no Squash runtime module or host executable is joined to the ROM.
- The new adapter, scripts, harnesses and source changes are Apache-2.0 unless stated otherwise. AsAsm and the observation fix remain governed by AsAsm's GPL-2.0-or-later license. The full host toolchain's original licenses and reconstruction materials remain in the preceding evidence chain.
- MacArch is an unchanged host verification dependency. Its GPL license and exact core-source provenance are retained. No emulator binary or emulator source is joined to the ROM, and no emulator modification was made.

`artifacts/diagnostics-review.json`, source manifests, patch replay and prior-artifact checksums make the actual inputs reviewable. Public availability alone is not being substituted for the recorded source license notices. This artifact remains an experimental component/CLI ROM, not a licensed copy of a proprietary RISC OS ROM distribution.

# Modifications and configuration decisions

All upstream source snapshots under `sources/` remain byte-identical to their pinned Git objects. SHA-256 verification precedes the reproduction build. Edits occur only in `build/` or in explicitly named local host adapters. Original copyright/licence notices are retained and modified files carry a change comment. No commit was made to an upstream repository.

## Kernel configuration

kernel-configuration.patch is generated by adapt-kernel.py against the pinned Kernel source.

| Selection / change | Reason and scope |
|---|---|
| `StrongARM = FALSE` | Selects existing non-StrongARM paths and disables its dependent CPU workarounds |
| `Interruptible32bitModes = FALSE` | ARM2 has no 32-bit processor modes; selects the existing 26-bit IRQ branch |
| `IncludeTestSrc = FALSE` | The selected POST external-command monitor requires ARM600 CP15 macros. The existing alternative in `s/Kernel` supplies direct-reset vectors. No claim is made about a tested replacement POST |
| `RO371Timings = FALSE` | Disables IOMD-ID-based ROM timing assumptions; retains existing older timing selection |
| `Select16BitSound = FALSE` | Source explicitly identifies pre-IOMD machines as lacking this link |
| `LCDSupport = FALSE` | A440/1 has the original external display and cursor path |
| `VCOstartfix = FALSE` | This is explicitly an A7000/7500FE VIDC20 oscillator workaround |
| Five `Chocolate…` switches = FALSE | Use the existing heap/module/variable/CLI/service fallback implementations; their newer workspace is absent from Old.NewSpace |
| Gate `back_to_user32` / `Do_CallBack32` with `Interruptible32bitModes` | Their sole external caller is already under that gate in NewIRQs. Makes the definition match its caller's feature selection; no 32-bit instruction is rewritten into a pretend ARM2 equivalent |
| Move `DTabC` declaration out of IOMD conditional | The same assembler loop counter is used by IOC interrupt tables |
| Unindent two non-LCD pointer blocks by four columns | Both locations explicitly say this is required to make them work again. Restores labels without changing the algorithm or instructions |

A440-experiment explicitly supplies later feature switches missing from the 1996 machine header. It identifies a desktop with original expansion slots, no STB/Phoebe/Morris/HAL, no Chrontel encoder, no added STB EEPROM, no IOMD front-panel/PAL-select bits, no reassigned IOMD interrupts and no fast-I2C/clock-suspension feature. Each declaration has its rationale in the file. This is deliberately enumerated; there is no “undefined means false” fallback.

The A440 machine header itself is unchanged. Its CPU, chipset, FDC and keyboard selections remain authoritative. `SystemName` is the source's normal RISC OS value. Version strings were not relabelled as RISC OS 3.11.

## Assembler dialect and export adaptations

- The old `ENTRY` macro conflicts with AsAsm's built-in directive, which ignored routine labels and stack-prologue behaviour. aasm-entry-macro.patch renames the macro and its uses to `KernelEntry`, retaining its exact body. The patch is applied after the configuration patch. `-Uppercase` retains traditional mnemonic/macro case behaviour. The final selected input manifest identifies the actual changed files; some prepared but unselected source files also receive the mechanical rename.
- `prepare.py` builds one explicit header-export tree. It applies later global interface exports first, overlays the original HdrSrc machine/macros, then Kernel and the required module interfaces. Ownership and hashes are in header-exports.json. Filename case follows each repository's actual export path, including `PortMan/Hdr` and `NVRAM/export/Hdr`.
- AsAsm's native filename mapping is used: `HDR_PATH`, `MACHINE` and `IMAGESIZE` are uppercase environment variables; the source retains `Hdr:` paths and RISC OS dotted include syntax. The original case-sensitive host issue was corrected after the first attempt.
- The native build wrapper uses `-ABSolute -Uppercase -cpu=ARM2 -apcs 3/26bit -aof`. AOF is an inspection/intermediate format here; no ROM-link stage was attempted.
- `BuildSys` is a pinned reference. No generic full-OS build or current product defaults are run.

## Tokeniser

tokenise-host.patch makes two host-C fixes: `memset(..., NULL, ...)` becomes integer zero, and a `size_t` diagnostic uses `%zu`. It does not change token selection or output generation. The generated `s/TMOSHelp` is derived only from the selected Apache-covered source files; its provenance is in the actual-input manifest.

## Host toolchain

The GCCSDK tool source is pinned at `212d4567f007e7d30f4af3d6e1919a3d8a115b1c`. AsAsm 2.01 and decaof 2.02 were built using the installed Apple Clang/macOS SDK, with local GNU M4 1.4.20, Autoconf 2.72 and Automake 1.17. Existing GNU Libtool is used from Homebrew. Nothing was installed system-wide.

- Local Autotools prefix and `ACLOCAL_PATH`/`LIBTOOLIZE` select the installed GNU Libtool macros.
- `--disable-shared` avoids GNU ELF version-script linker flags on Darwin; only the bundled object-file libraries are needed.
- sys/endian.h maps native Darwin byte-order definitions. The ARM ELF target is configured separately.
- ieee754.h supplies the native IEEE-754 unions used by AsAsm on little-endian Darwin. Its compile-time guards and native layout test passed. No adapter code is linked into target output.
- The Make invocation supplies a deterministic numeric tool version `2010000` and the real full Git revision because the shallow Git conversion lacks usable SVN version metadata. This is not represented as an upstream SVN release number.
- An optional diagnostic build raised AsAsm's 30-error limit to 10,000, with the one-change patch. It did not change instruction encoding, but encountered a later assertion. The upstream error limit was restored for the final build. The separate diagnostic binary/log remain local evidence.
- Configure regenerates the tracked ELF toolchain `GNUmakefile`; this is generated build-system output, not a hand-edited implementation. No upstream assembler encoding source was changed.

## Work intentionally stopped

No edits were made to invent old-machine workspace allocations, substitute IOMD constants, remove the hard-reset page-table calls, bypass AMB initialisation, implement an alternative memory manager, patch in reference ROM bytes, integrate a desktop or modify MacArch. Those would exceed the demonstrated build/configuration repairs and require a new reviewed milestone.
